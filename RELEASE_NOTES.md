### 🚀 What's New in v1.0.3

- **Full On-Device Android & Gradle Builds**: Build complete Android apps (Java/Kotlin + C/C++ NDK) directly on your device with Gradle 8.5 and OpenJDK 17. Automated APK artifact discovery and direct 1-tap installation.
- **Automated SDK & NDK Provisioning**: Automatic installation and setup of Android SDK Platform 34, Build-Tools with native ARM64 AAPT2, and Clang NDK toolchains with automatic linker and makefile compatibility fixes.
- **Integrated AI Agent Chat & Custom Endpoints**: Interactive coding assistant in the editor with chat history, streaming typewriter animation, thinking blocks, and support for Custom OpenAI-compatible endpoints alongside Antigravity & AI Studio.
- **Fast Build Startup & UI Improvements**: Optimized build initialization time, improved bottom sheet diagnostics, fixed Export SO dialog layout, and centered AI provider segmented buttons.
