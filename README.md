# PrismDE

**PrismDE** — современная среда разработки (IDE) для Android устройств, позволяющая создавать, редактировать и собирать C/C++ проекты с помощью **Android NDK** прямо на устройстве.

## Возможности
- 💎 **Material 3 Expressive & Google Typography**: Интерфейс выполнен в новейшем стиле Google Material 3 Expressive со шрифтом Inter и плавными анимациями на физических пружинах (spring physics).
- ⚙️ **Сборка через NDK**: Поддержка Clang, LLVM, CMake, Ninja и ndk-build.
- 📦 **Умный режим для чистого JNI (.so)**: Если проект содержит только папку `jni/`, PrismDE собирает исключительно `.so` библиотеку без необходимости разворачивать проект Android Studio.
- 🎯 **Интерактивная диагностика**: Ошибки парсятся в реальном времени с поддержкой Clang Fix-It и понятными русскими объяснениями. Нажатие на ошибку мгновенно открывает строку в коде и предлагает автоматическое исправление.
- 🤖 **AI-ассистент (Опционально)**: Интеграция с Google Gemini API для глубокого анализа сложных шаблонных ошибок и подсказок по рефакторингу.
- 📥 **Менеджер версий NDK**: Автоматическая загрузка, распаковка и переключение между релизами NDK (r23c, r25c, r26c, r27) с поддержкой докачки (HTTP Range).
- 🚀 **Авто-обновления**: Проверка и установка новых версий APK прямо из [GitHub Releases](https://github.com/lonxzsy/prismde/releases).
